## 1. Purpose

Problem resolution management: development findings, test anomalies, safety anomalies and field reports, from intake to closure, with the `safety-anomaly` stop rule of WP-M-02 §9.

## 2. Intake

GitHub issues with the problem report and safety concern templates; labels.

## 3. Triage and classification

Safety anomaly within one working day; severity classes; the stop rule.

## 4. Root cause and corrective action

Linked to the nonconformance and corrective-action records of WP-M-05.

## 5. Closure

Verification evidence; feedback into the analyses (WP-O-04 §5).
