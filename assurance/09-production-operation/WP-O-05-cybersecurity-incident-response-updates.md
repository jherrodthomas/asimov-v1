## 1. Purpose

Cybersecurity incident response, vulnerability management and software updates (IEC 62443-4-1 DM and SUM): the private disclosure channel, triage, fixes, advisories, signed updates and rollback.

## 2. Disclosure and triage

The [security policy](../../SECURITY.md); acknowledgement and assessment times; the stop notice for a vulnerability that can move the robot or defeat a stop.

## 3. Updates

Signed images, staged roll-out, rollback, the record of what each unit runs.

## 4. Advisories

Format, timing, coordination with upstream.
