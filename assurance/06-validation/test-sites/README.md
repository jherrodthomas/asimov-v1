# Test sites and session logs

One file per test area (`<site>.md`: sketch, dimensions, floor, markings, gantry span and height, exits) and one log
per session (`<YYYY-MM-DD>-<site>.md`) in the format of [WP-V-07 §5](../WP-V-07-test-operations.md#5-test-log).

No site is defined and no session has been run under the fork's control. The first site is the development test area
of [WP-C-02 §6](../../02-concept/WP-C-02-operating-environment-and-tasks.md#6-the-development-test-area-oe-1).
